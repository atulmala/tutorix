# Student booking history

Students see the same purchase history tutors already have. One row is every class credit that shares an order item. Columns match the tutor table, with the tutor name in place of the student name: booking date, tutor, offering, classes booked, mode, scheduling status, concluded status, and amount.

Search is two dropdowns, Tutor and Subject. Options come from that student's own bookings. Choosing a value filters with an exact match, and the two filters combine. Web shows a paginated table. Mobile shows scrollable cards, with the dropdowns behind a Search bookings control.
