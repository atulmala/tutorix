# Web home vs profile

Mirror the mobile home/profile split on the tutor/student web app.

- Onboarded students and tutors land on home, not profile.
- Header: left avatar opens profile (or back on profile/wallet); wallet chip before logout.
- Profile pages keep photo upload in the hero. Wallet chip moves to the header.
- Wallet back returns to the screen that opened it.
