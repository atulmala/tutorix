# Tutor booking history

Show tutors their class purchase history.

Web: a separate screen with a paginated table. Columns are booking date, student name, offering, number of classes booked, mode (online/offline), scheduling status, concluded status, and amount. Search by student login email or mobile, offering name, scheduling status, and conclusion status.

Mobile: the same details as vertically scrollable cards, with the same filters and a load-more control.

One row is every class credit that shares an order item for the signed-in tutor. Amount is the student-paid line total. Demo bookings are included at ₹0.
