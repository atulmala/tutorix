# Agora live online classroom

A booked online class opens five minutes before the start. For a 3:00 pm class that lasts 60 minutes, the tutor or an enrolled student can join at 2:55 pm. At 3:55 pm everyone still in the room sees “Wrap up in the next 5 minutes.” The call may continue until 4:05 pm, then it ends.

Web and mobile join the same video channel, the same chat channel, and the same whiteboard room. A tutor on one app and students on the other see the same board, the same video, and the same class chat. Anyone in the class can share one screen at a time. The tutor and students can all draw.

Secrets stay in the local environment and in AWS Secrets Manager. They are not written in this plan.
